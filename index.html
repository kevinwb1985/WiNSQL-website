核心特色

SQL 智能编辑器

语法高亮、错误标记、自动补全、多语句执行。支持 SqlServer、Oracle、MySQL、PostgreSQL、达梦五种数据库方言。

一键发布 API

SQL 语句直接发布为 RESTful 接口，无需编码。客户端编写、服务端托管，一条 SQL 即一个可调用服务。

🔄

跨库 SQL 翻译

5 种数据库函数自动翻译，告别手动改写。SqlServer、Oracle、MySQL、PostgreSQL、达梦间无缝切换。

📡

内置调试工具

Postman + SoapUI 工作台内置，接口调试零切换。HTTP 请求测试与 SOAP 协议调试一站式完成。

🎨

双主题系统

深色 / 浅色主题自由切换，字体大小可调。遵循 WCAG 无障碍标准，适配不同工作环境与视觉需求。

集群与治理

服务端集群管理、负载均衡、自动故障转移。内置熔断器与限流配置，保障 API 服务高可用。

服务端

WiNSQL Server 服务端

将客户端发布的 SQL 接口部署为生产级 API 服务，支持集群管理、流量治理与运维监控

📥

接口管理

统一管理客户端发布的 REST API 接口，支持接口启用/禁用、在线测试、参数查看与版本管理

🧩

集群管理

多节点集群统一管理，实时监控各节点运行状态，支持节点上下线与负载均衡策略配置

⚡

熔断器配置

自动熔断异常接口，防止故障扩散。可配置错误率阈值、熔断时长与半开恢复策略

📦

限流配置

按接口或 IP 维度配置请求限流，支持令牌桶与滑动窗口算法，保护后端数据库不被压垮

📄

日志中心

实时查看服务端运行日志与接口调用记录，支持按级别、时间、关键词筛选，快速定位问题

🚀

多平台部署

支持 Windows Server、Linux 与 Docker 容器化部署，适配各类企业基础设施环境

Windows Server Ubuntu / CentOS Docker systemd
